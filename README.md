# Smasher Annual Offer Landing Page

## كيفية تشغيل الصفحة محليًا
1. في مجلد المشروع شغّل خادمًا محليًا بسيطًا:
   ```bash
   python -m http.server 8000 --bind 0.0.0.0
   ```
2. افتح المتصفح على هذا الرابط المحلي وستكون الصفحة جاهزة:
   ```
   http://localhost:8000/
   ```

> لو حابب تغيّر المنفذ، عدّل الرقم في الأمر والرابط.
